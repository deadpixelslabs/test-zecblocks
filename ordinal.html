How is the artwork stored?

The SVG generator lives in a dedicated contract created together with the collection. Every NFT has a fixed design code. The collection returns the image and metadata directly from blockchain reads, without an external image database.

What are the mint rules?

The collection is capped at 5,000 NFTs. Each transaction mints one NFT for exactly 0.00019 ETH in protocol fees, plus network gas. There is no lifetime wallet mint limit, premine, admin mint, or configurable fee. Trait assignment is deterministic; it is not a random lottery.
